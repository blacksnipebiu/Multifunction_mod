# Multifunction_mod 4.0.7

多功能 OP 面板 mod：人物、建筑、星球、戴森球、战斗、机甲物流等一站式修改与便捷功能。

默认快捷键 `Alt + 1`
语言/Language：中文，English

<details>
<summary><b>📖 功能总览 · 界面说明 · 使用指南（点此展开）</b></summary>

> 本 mod 的大部分功能属于"作弊/OP"类，**可能导致成就与元数据失效**；"解锁全部科技""初始化玩家""瞬间完成戴森球"等不可逆操作，使用前请先存档。
> 所有开关默认关闭，需要时在面板里手动勾选，配置会自动保存到
> `BepInEx/config/cn.blacksnipe.dsp.Multfuntion_mod.cfg`。

### 一、快速上手

| 操作 | 效果 |
| --- | --- |
| `Alt + 1` | 开 / 关主面板（默认快捷键，可在「其它功能」里改） |
| 拖动标题栏 | 移动面板 |
| 拖动边缘 | 缩放面板 |
| `Ctrl + ↑ / ↓` | 调整面板字号（5–35，默认 16） |
| 面板内滚轮 | 滚动当前页签内容 |
| 面板内点击 | 面板打开时会阻挡点击穿透，不会误点到背后的建筑 |

- 面板贴合在游戏画面之上，打开/移动/缩放时会同步一次位置与大小，窗口位置、尺寸、字号都会记住。
- 面板内容较多，左下角为页签栏；右侧内容区可滚动。

### 二、主面板界面

标题栏显示 `OP面板(4.0.7)ps:ctrl+↑↓`，下方是 7 个页签（当前页签高亮）：

**人物** · **战斗** · **建筑** · **星球** · **戴森球** · **其它功能** · **机甲物流**

<details>
<summary><b>① 人物</b> —— 属性修改、背包、科技</summary>

- **启动属性修改**：左侧列出人物当前能力（移动/飞行/采矿/制造等，可拖动滚动条），拖动修改后必须点右侧「启动属性修改」才会真正应用。
- **无限物品 / 无限沙土 / 无限元数据**：背包物品不减少、沙土不减少、元数据锁定为 9999999。
- **小飞机不耗能 / 无限机甲能量**：建筑小飞机不消耗能量、机甲能量锁定为满。
- **启用传送**：星图上选中星球后可直接快速传送（需先勾选本项）。
- **科技点击解锁**：在科技树里点选科技节点，直接补足消耗并逐级解锁到满级。
- **不往背包放东西**：拆除建筑时不把物品放回背包（物流站内物品会在拆除时返还）。
- **鼠标中键锁定玩家背包格子Max**：鼠标中键点击背包格子，直接把该格堆叠到上限。
- **机甲制造MAX / 机甲采矿MAX**：手动制造瞬间完成、手动采矿瞬间完成。
- **研究秒完成**：科技进入研究队列后立即完成。
- **直接获取物品**：复制机（制造台界面）里点选配方，直接获得产物到背包。
- **无需翘曲器曲速飞行**：曲速飞行不消耗翘曲器。
- **清空背包 / 初始化玩家**：清空背包；把机甲与背包重置为初始状态（要求所有存活小飞机都在身上）。
- **背包**：`加一行` / `加一列` / `减一行` / `减一列` 调整机甲背包容量。
- **解锁全部科技 / 回退无穷科技**：一键解锁全部科技（不可逆）；回退无限等级的科技。

> 提示：飞行速度不要改太高，可能导致机甲持续浮空、无法用 `Alt` 降落。

</details>

<details>
<summary><b>② 战斗</b> —— 锁血、攻速、黑雾控制</summary>

- **玩家锁血 / 建筑锁血 / 怪物锁血**：对应目标血量锁定为上限。
- **玩家攻速Max**：机甲激光射速拉满、能量不消耗。
- **玩家假死**：黑雾不再把玩家当作目标，地面/太空仇恨清空。
- **炮塔永久超新星**：炮塔持续处于超新星状态；勾选「启用快捷键(ctrl+s)」后可用 `Ctrl + S` 快速开关。
- **点击生成中继站 / 点击杀死敌人**：鼠标点击生成黑雾中继站/杀死敌人；「点击模式」可选择 `点按` 或 `按压`，并支持「基地核心连锁拆除」。
- **威胁度控制**：`星球永远0威胁` / `太空永远0威胁` / `玩家所在星球永远满威胁` / `玩家所在星系永远满威胁`（互斥项建议只开一个）。
- **调整黑雾怪物等级**：设定等级数值后，可「设置当前星球黑雾等级」「设置当前星系太空黑雾等级」。
- **黑雾巢穴快速产怪**：黑雾巢穴快速刷新单位。
- **启动属性修改**：同人物页，确认后才应用。

</details>

<details>
<summary><b>③ 建筑</b> —— 物流站、矿机、电力、储液站、量子传输</summary>

**物流站功能**

- **额外存储倍率**：物流站额外储量 = 站本身基数（小站 5000 / 大站 10000）× 倍率。
- **永久满电**：物流站充电槽永远满。
- **要啥有啥**：全游戏所有物流站清单物品数量无限。
- **无限增产 / 内置喷涂**：清单物品自动带三级最高增产点数；或把 3 级增产剂放在清单任意格，自动增产塔内其他物品。
- **内置发电**：消耗清单最后一格带燃料值的物品来供电。
- **无限翘曲**：星际运输站翘曲不消耗。

**以下功能需要给物流站改名**

- **星球无限供货机**：指定名字的物流塔内清单物品数量无限。
- **垃圾站 / 需要沙土**：输入该名字的物流塔会销毁投入的物品；勾选「需要沙土」则按比例转化为沙土。
- **星球矿机 / 采矿速率**：改为该名字的物流塔会按速率采集整个星球的矿脉并存入塔内。
- **喷涂加工厂**：改名后把 3 级增产剂放在清单任意格，自动增产塔内其他物品。
- **星球熔炉矿机 / 等价高级熔炉数量**：检索塔内清单，按"等价高级熔炉数量"对应的产能每 0.5 秒熔炼一次（例如铁矿→铁板→钢材一条龙）；耗能 = 2 级熔炉单次耗能 × 数量。
- **自动改名**：填写的名字会在新建物流站时自动写入（不填则不生效）。

**其它建筑功能**

- **建造数量最大值**：单次铺设的最大建筑数量（默认 15）。
- **操作范围不受限制**：交互/建造距离不受限。
- **建筑秒完成**：预建造立即完成。
- **蓝图建造无需材料**：蓝图粘贴不消耗材料。
- **建筑师模式**：所有建筑道具无限使用（不影响已有数量）。
- **建筑抬升 / 抬升层数**：传送带预览按设定层数抬升。
- **传送带信号功能**：请阅 B 站视频介绍。

**电力设备**

- **新建设备不耗电**：新建的用电设备耗能为 0。
- **人造恒星无限能源 / 星球电网(人造恒星)**：人造恒星燃料与发电量拉满；「覆盖全球」「超长连接」扩展电力感应塔覆盖与连接距离。
- **风力涡轮机无限能源 / 覆盖全球**。

**储液站功能**

- **储液站任意存**：储液罐可存取任意物品（不限液体）。
- **无限储液站**：储液罐可无限接收原料。
- **储液站无限增产**：进入罐内的物品自动获得三级最高增产点数。

**量子传输站**

- 勾选「量子传输站」后可选择「星球级」或「星系级」，并为采集器、物流站、矿机、发射井/弹射器、研究站、电力设备、组装机分别配置供应/拿取。
- 使用时配合「自动改名」拍下对应物流塔；用完请取消自动改名，否则后续新拍的物流塔都会变成量子站。
- 量子站与星球矿机冲突，如需同时使用请用独立版本；量子供应清单项状态必须为"供应"才生效。
- 可实时修改星球级/星系级量子充电功率。

<summary><b>④ 星球</b> —— 矿物生成与编辑、海洋</summary>

- **矿物模式**：`删除矿物`、`移动单矿`、`移动矿堆`、`不排列`、`整理所有矿`、`整理为`、`切割矿脉` / `切割出 N`、`点按` / `按压`。
- **添加油井速率 / 添加矿脉数量**：`500` 或 `无穷` 两种档位。
- **海洋**：`还原海洋`、`设置当前星球海洋类型`（需先填写海洋名称，如"硫酸"）、`恢复所有星球海洋类型`。
- **铺平整个星球**、**超密铺采集器**（需机甲在冰巨/气巨星上，慎用）等大范围操作也在本页。

</details>

<details>
<summary><b>⑤ 戴森球</b> —— 画壳、弹射、太阳帆</summary>

> 注意事项：戴森云和戴森壳不要出现"一层轨道都没有"的情况，用前存档。

- **点击删除下列戴森壳层级**：勾选后可点击层号删除该层。
- **初始化当前戴森球**：清空当前戴森球结构。
- **瞬间完成戴森球**：直接完成当前球（用前存档）。
- **极速轨道弹射器 / 极速垂直发射井**（慎用）。
- **跳过太阳帆子弹阶段 / 跳过太阳帆吸收阶段**：省去打帆飞行与吸收阶段，太阳帆直接入轨。
- **太阳帆帧吸收**：控制每帧吸收个数。
- **全球打帆**：弹射器全球布置并持续打帆。
- **开放戴森壳半径上下限**：可设置最小/最大半径（用前存档）。

</details>

<details>
<summary><b>⑥ 其它功能</b> —— 全局开关、界面外观、快捷键</summary>

以下设置需要**进入存档后**生效：

- **关闭异常提示**（不屏蔽游戏防作弊检测）。
- **取消总控面板本地限制**：总控面板可跨本地/星际限制操作。
- **增产点数上限10**：单个物品增产点数上限提到 10（三级增产约额外产出 40% / 加速 150%）。
- **蓝图强制粘贴**：蓝图条件不满足也可粘贴。
- **建筑铺设无需条件**：传送带/插入机等铺设无需条件。
- **关闭所有碰撞体**：关闭场景碰撞体。
- **全部手搓**：所有配方可在机甲上直接手搓。
- **快速生产**：产出设备生产周期极短；关闭时先取消勾选并重新进档。
- **堆叠倍率**：输入 1–5000000 后点「设置」，修改全局物品堆叠上限。

其它：

- **窗口颜色及透明度**（RGBA）、**窗口字体颜色**：面板外观自定义。
- **快捷键**：点击后按下新组合键即可修改面板开关快捷键。
- **取消所有勾选**：一键关闭全部功能开关。

</details>

<details>
<summary><b>⑦ 机甲物流</b> —— 物流背包自动补货与回收</summary>

- **强化机甲物流**：启用后，物流背包里的设置会直接从全星系的储物仓/物流站取货或回收；若物流背包未解锁会自动解锁一列。
- **机甲物流专用星**：设置后只有名字符合的星球才启用（按面板提示填写星球名）。
- **优先度**：可分别设置「所有物品」「玩家背包」「物流背包」「建筑物品」的优先顺序。
- 回收/需求可分别选择使用「储物仓」或「物流站」。

</details>
